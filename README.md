# GDABVI Website

Static website build for the Greater Detroit Agency for the Blind & Visually Impaired.

## Contents

- `index.html` is the homepage entry point.
- `assets/` contains the compiled CSS, JavaScript, photos, logos, and badges.

## GitHub Pages

After this folder is pushed to GitHub:

1. Open the repository on GitHub.
2. Go to `Settings` > `Pages`.
3. Set the source to deploy from the `main` branch and the repository root.
4. Save. GitHub will provide a live Pages URL.

## Notes

- Donate/payment backend is not connected yet.
- Some resource schedule details are archive-derived and should be confirmed by GDABVI before publishing as current.
